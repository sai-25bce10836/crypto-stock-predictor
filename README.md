# Stock and Cryptocurrency Trend Prediction using Machine Learning

##  Overview

This project is a Machine Learning-based system that predicts whether the price of a stock or cryptocurrency will move **UP or DOWN** based on historical market data.

It uses real-time data fetched from Yahoo Finance and applies a Logistic Regression model for prediction.

---

## 🎯 Features

*  Uses real financial data (stocks & crypto)
*  Dynamic user input (symbol & date range)
* Supports Indian stocks (e.g., RELIANCE.NS)
*  Machine Learning-based prediction (UP/DOWN)
* Displays model accuracy

## Technologies Used
* Python
* Pandas
* Scikit-learn
* yfinance

## Installation

1. Clone the repository:

```
git clone <your-repo-link>
cd <your-folder-name>
```

2. Install required libraries:

```
pip3 install -r requirements.txt
```

---

## ▶️ How to Run

Run the following command:

```
python3 main.py
```

---

## 📝 Usage

Enter the following when prompted:

* Stock/Crypto Symbol
  Examples:

  * BTC-USD (Bitcoin)
  * AAPL (Apple)
  * RELIANCE.NS (Indian stock)

* Start Date (YYYY-MM-DD)

* End Date (YYYY-MM-DD)

* Next Day Prediction:
